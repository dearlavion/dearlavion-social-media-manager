New posting tool

Posting tools are the backends that actually publish a post (set per channel on the Dashboard as "Posting tool"). Only Buffer is implemented today:

  1. Create a free account at buffer.com and connect the accounts you want to post to from Buffer's own dashboard.
  2. Get a personal API key: buffer.com/settings/api.
  3. Add it as a GitHub repo secret named BUFFER_ACCESS_TOKEN (shared across every project).
  4. For each channel, look up its Buffer channel id via Buffer's GraphQL API — see the Wiki for the exact query.

Adding a different tool (a direct platform API, or another free service) means writing one new module in automation/src/publishers/ matching the existing PublishFn pattern and registering it — it then appears here and in the Dashboard's Posting tool dropdown automatically.
